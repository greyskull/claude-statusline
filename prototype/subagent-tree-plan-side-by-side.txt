YAS -- tree-mode plan + subagents side-by-side, ASCII glyph mode
==================================================================

Scenario: subagent-tree-plan (checklist column + tree-mode subagent cohort
side by side; exercises the ~78-col plan-column cap rather than the old
45%-of-inner even split). Included specifically because, unlike the
single-column SUBAGENTS section above, this side-by-side layout still only
labels the two group headers ("plan" / "subagents") -- it does NOT carry the
per-column labels ("name" / "loc read / written" / "model" / "current
activity") down into the subagents half. That's a real, currently-shipped
gap worth eyeballing, not a demo-harness artifact.

Generated with:
  env -u TMUX_PANE -u TMUX COLUMNS=<N> YAS_GLYPH_MODE=ascii YAS_LABELS=true \
    DEMO_ONLY=subagent-tree-plan uv run python ops/demo.py --snapshots <dir>
  .claude/skills/yas-demo-text/scripts/strip-ansi.sh <dir>/subagent-tree-plan.txt

(yas.toml for this scenario sets max_width=300, so widths up to ~300 render
at their requested COLUMNS instead of being clamped to the 140 default.)
